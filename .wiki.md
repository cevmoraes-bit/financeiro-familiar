# Project Summary
**FinControl** é um aplicativo de controle financeiro pessoal, projetado para ser responsivo e utilizável tanto em dispositivos móveis quanto em desktops. Ele permite que os usuários registrem despesas e receitas de forma rápida e fácil, com dados sincronizados em tempo real através de um backend seguro. O aplicativo oferece uma visão clara do saldo e das transações, ajudando os usuários a gerenciar suas finanças de maneira eficiente. Recentemente, melhorias foram feitas na autenticação do usuário e na interface, incluindo a atualização do texto do botão de login.

# Project Module Description
- **Auth**: Gerencia a autenticação de usuários via Atoms Cloud, agora utilizando `client.auth.toLogin()` corretamente.
- **Dashboard**: Exibe um resumo financeiro mensal, incluindo saldo, receitas e despesas.
- **Transactions**: Permite a listagem, filtragem e exclusão de transações.
- **AddTransaction**: Formulário para registrar transações rapidamente.
- **Layout**: Navegação mobile-first com design responsivo.

# File Description Inventory
- **app/backend**: Contém a lógica do servidor, incluindo autenticação, rotas da API e manipulação de dados.
- **app/frontend**: Contém o frontend React, incluindo componentes, páginas e estilos, com melhorias recentes na autenticação.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS
- **Backend**: Atoms Cloud (PostgreSQL, Auth)
- **Database**: PostgreSQL via Atoms Cloud
- **Authentication**: Atoms Cloud OIDC, agora utilizando `client.auth.toLogin()`.

# Usage
1. **Instalação de Dependências**:
   - Navegue até o diretório do frontend e execute:
     ```
     pnpm install
     ```
2. **Construir o Projeto**:
   - Execute o comando de build:
     ```
     pnpm run build
     ```
3. **Rodar o Linter**:
   - Para verificar a qualidade do código, execute:
     ```
     pnpm run lint
     ```
