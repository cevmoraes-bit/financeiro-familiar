# Requirements & Progress

## Requirements Overview
App de controle financeiro pessoal responsivo (mobile-first) com backend para sincronização de dados entre celular e computador.

## User Stories
- Como usuário, quero registrar despesas e receitas rapidamente do celular
- Como usuário, quero ver meu saldo e gastos do mês no dashboard
- Como usuário, quero categorizar minhas transações
- Como usuário, quero filtrar e buscar transações anteriores
- Como usuário, quero acessar de qualquer dispositivo com dados sincronizados
